# Documentation

Welcome to the LeiOS documentation. LeiOS is a free operating system for PCs and laptops, built on
Debian 13 with a polished KDE Plasma desktop. These docs take you from the download to a system
that is entirely yours, and further, if you want to build packages for LeiOS or help develop it.

New to Linux? You are in the right place. Every guide is written for people who have never used
Linux before, and explains each step.
