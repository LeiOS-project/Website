# The Desktop

LeiOS uses **KDE Plasma 6**, a modern desktop that works the way most people expect: a panel at the
bottom of the screen, a menu for your apps, and windows you can move, resize and snap side by side.
This page shows you around.

## The panel

The bar at the bottom of the screen is the **panel**. From left to right it has:

- **The Application Launcher** (the LeiOS logo): all your apps, a search field, and buttons to
  log out, restart and shut down. Press the :kbd{value="Meta"} key (the Windows key) to open it.
- **The task manager:** pinned apps and the windows that are open. Right-click an open app and
  choose **Pin to Task Manager** to keep it there.
- **The system tray:** network, volume, battery, Bluetooth, clipboard, notifications and updates.
  Click the small arrow to see all icons.
- **The clock:** click it for a calendar.

To change the panel, right-click it and choose **Show Panel Configuration**. You can move it,
change its size, and add widgets such as a weather report or a system monitor.

## Finding things

Start typing in the Application Launcher, or press :kbd{value="Alt"} + :kbd{value="Space"} to
open **KRunner**, the search bar at the top of the screen. Both find apps, settings, files and
recent documents, and KRunner can also do calculations (`12*7`) and unit conversions
(`5 miles in km`).

## Windows

- **Snap** a window to one half of the screen by dragging it to the left or right edge, or with
  :kbd{value="Meta"} + arrow keys. Drag it to the top edge to maximize it.
- **Switch** between windows with :kbd{value="Alt"} + :kbd{value="Tab"}.
- **Overview:** press :kbd{value="Meta"} + :kbd{value="W"} to see all windows and virtual
  desktops at once.
- **Virtual desktops** give you separate workspaces, for example one for work and one for
  everything else. Set them up in *System Settings → Virtual Desktops*.

## Files

**Dolphin** is the file manager. Your files live in your **home folder**, in **Documents**,
**Downloads**, **Pictures**, **Music** and **Videos**. USB sticks, external drives and other
partitions show up in the sidebar under **Devices** as soon as you plug them in.

- Press :kbd{value="F4"} for a terminal panel inside Dolphin, at the current folder.
- Press :kbd{value="Ctrl"} + :kbd{value="H"} to show hidden files and folders (their names start
  with a dot).
- Right-click a file for actions such as compressing, extracting, or sending it to your phone.

## Settings

**System Settings** is the one place for all settings: displays, Wi-Fi, sound, printers,
Bluetooth, users, appearance and more. Use the search field at the top left if you don't know where
something is.

| --- | --- |

| **Plasma Vault** | Encrypted folders for sensitive files, in the system tray. |

## Keyboard shortcuts

The :kbd{value="Meta"} key is the key with the Windows logo.

| Shortcut | What it does |
| --- | --- |
| :kbd{value="Meta"} | Open the Application Launcher |
| :kbd{value="Alt"} + :kbd{value="Space"} | Search with KRunner |
| :kbd{value="Meta"} + :kbd{value="E"} | Open Dolphin |
| :kbd{value="Ctrl"} + :kbd{value="Alt"} + :kbd{value="T"} | Open Konsole |
| :kbd{value="Meta"} + :kbd{value="L"} | Lock the screen |
| :kbd{value="Meta"} + :kbd{value="D"} | Show the desktop |
| :kbd{value="Meta"} + :kbd{value="W"} | Overview of all windows |
| :kbd{value="Meta"} + arrow keys | Snap the window to a side or corner |
| :kbd{value="Alt"} + :kbd{value="Tab"} | Switch windows |
| :kbd{value="Meta"} + :kbd{value="V"} | Clipboard history |
| :kbd{value="Meta"} + :kbd{value="."} | Emoji picker |
| :kbd{value="Print"} | Take a screenshot with Spectacle |
| :kbd{value="Ctrl"} + :kbd{value="Esc"} | Open System Monitor |
| :kbd{value="Alt"} + :kbd{value="F4"} | Close the window |

All shortcuts can be changed in *System Settings → Keyboard → Shortcuts*.

## Learn more

LeiOS uses KDE's apps and desktop as they are, with the LeiOS look on top. The
[KDE UserBase wiki](https://userbase.kde.org){target="_blank"} and the **Help** menu of each KDE app
(the *KDE Help Center* is installed) explain everything in detail.
